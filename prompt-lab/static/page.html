    About the Prompt Lab

    Describe a part; a modeling agent builds it as a parametric Gendl model you can inspect, adjust and edit.

    An experiment, offered as is, with no guarantees about what gets built. Your prompts and the generated code are logged. Generated code is yours under the GNU Affero General Public License, like Gendl itself. Each session allows a handful of prompts; take a copy of the model file if you want to keep it.

    The lab can be installed as an app: Install among the commands where the browser offers it, Add to Home Screen in the browser's own menu on a phone. Installed, it opens on the session you were last in. It still needs its connection: only the page itself is kept on the device.

    Sessions are open to view: other visitors can browse your prompts, the agent's replies and the model, live and later in the archive, but only this browser can prompt, edit or buy credits in the sessions it opened. A session that has bought modeling credits can be made private.
